Import Mail

Copy the mail from an account on another IMAP server into one of this box’s mailboxes. Folders, flags and message dates are kept. The copy is one-way: nothing changes on the old server and nothing already in the mailbox here is removed, so it is safe to run again to pick up mail that arrived in the meantime.

The mailbox on this box. Add the user first if it doesn’t exist yet.
Used for this import only. It is not stored. Providers such as Gmail need an app password.
