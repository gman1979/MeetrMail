Spam Filtering

Spam filtering is done by Rspamd. Every message gets a score. Above the greylist threshold a first-time sender is asked to try again shortly, above add header the message is marked as spam and filed in the Spam folder, and above reject it is refused outright. Nothing is ever silently discarded.

Thresholds

reset to defaults
  • Lower numbers are stricter. The thresholds must be in increasing order: greylist ≤ add header ≤ reject. Setting the greylist equal to add header turns greylisting off.
  • The defaults are 4, 6 and 15. The reject threshold is deliberately high: on a personal mail server a wrongly refused message costs more than a spam in the Spam folder.
